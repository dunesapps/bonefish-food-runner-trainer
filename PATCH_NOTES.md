# Bonefish Food Runner Trainer — Patch Notes

One entry per build. Build channels: Alpha 100s, Beta 200s,
Prod 300s.

## Build 300.7 — Prod — Nov 21, 2026

- Quiz no longer uses the Bundles tab for dishes that live on other tabs.

## Build 300.6 — Prod — Nov 21, 2026

- Added a Tablet Sim training track with the full POS tablet.
- Quiz shows a picture of each POS tab.
- Hub PCs are smaller.
- Two-entree tables now get two drinks.

## Build 300.5 — Prod — Nov 21, 2026

- Quiz now teaches which POS tab each item is on.
- Item cards and quiz answers show the POS tab.

## Build 300.4 — Prod — Nov 21, 2026

- Combined food and drinks into one training pool.
- Drinks now arrive with table orders instead of going to the bar.
- Barstool orders are food only.

## Build 300.3 — Prod — Nov 21, 2026

- Drinks deck corrected against the study guide.
- Added garnishes for all drinks, with garnish questions.
- Added Social Hour Cocktails, Mimosa, Bloody Mary, and Whistlepig Old Fashioned.
- Removed Chocolate Martini and Indigo Sunset.
- Added illustrations for all guide drinks.
- Fixed seasonal items in the quiz. Added a Seasonal only drill.

## Build 300.2 — Prod — Nov 20, 2026

- Added a drinks deck: martinis, cocktails, wines, beers.
  Drinks deliver to the barstools.
- Training terminals moved to the lower left corner by the
  front door. Smaller, rings at the desks. Exit ring
  unchanged.
- Most description questions replaced with ingredient list
  questions. Wrong lists have one or two ingredients
  swapped.
- Added weight questions for dishes with a stated weight.
- Quiz rotation reworked: dishes you know return less
  often, in different forms. Dishes you miss appear more.
- Added a Patch notes view in the game.

## Build 300.1 — Prod — Nov 19, 2026

- The game now shows its build number, small in the header:
  "Build 300.1". Future updates bump the number so you can
  always tell which version you are playing.
- No gameplay changes in this build.
