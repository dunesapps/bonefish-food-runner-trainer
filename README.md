# Bonefish Food Runner Trainer

A 2D food runner practice game built on the exact floor layout of the Bonefish Grill in North Wales, PA (Airport Square), bar and patio included. Made for learning the table numbers cold before a floor chart test.

## How to play

Open `index.html` in any browser. It is a single self-contained file with no dependencies.

- The bell rings and a tray with a table number appears at the expo pass in the kitchen. Walk in and pick it up.
- Carry the tray to the right table. The number rides on the tray while you carry it.
- Tables have no number labels on purpose. Bumping the wrong table tells you which one you hit and which one you need.
- After each delivery you reappear at the kitchen pass 2 seconds later, ready for the next ticket.
- Tickets deal from a shuffled deck of all 62 tables, so no number repeats until every table has come up once.
- **Hint** toggle: when on, your assigned table glows. When off, you navigate from memory.
- Controls: WASD or arrow keys on a keyboard, on-screen D-pad on touch screens. Sound toggle in the corner.

The kitchen pass doors are one-way, like the real thing: right door in, left door out.
